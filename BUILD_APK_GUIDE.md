# 📱 ИНСТРУКЦИЯ ПО СОЗДАНИЮ APK ФАЙЛА

## Что такое APK?
APK (Android Package) — это файл, который можно установить на любой Android телефон. После создания APK файл можно отправить кому угодно, и они смогут установить приложение на свой телефон.

## Требования

### 1. Установленное ПО
- Node.js (уже установлен)
- Expo CLI: `npm install -g expo-cli`
- EAS CLI: `npm install -g eas-cli`
- Git (для управления версиями)

Проверить установку можно командами:
```bash
expo --version
eas --version
```

### 2. Учетная запись Expo

Вам потребуется бесплатная учетная запись на https://expo.dev

1. Перейти на https://expo.dev
2. Нажать "Sign Up"
3. Создать аккаунт (email и пароль)
4. Подтвердить email

После создания аккаунта, авторизоваться в терминале:
```bash
eas login
```

Введите ваш email и пароль.

## Способ 1: Быстрое создание APK (рекомендуется)

### Шаг 1: Подготовка проекта

Перейти в корневую директорию проекта:
```bash
cd C:\Users\mvant\TheStillness
```

### Шаг 2: Проверить app.json

Убедитесь, что файл `app.json` содержит правильную информацию:

```json
{
  "expo": {
    "name": "TheStillness",
    "slug": "thestillness",
    "version": "1.0.0",
    "platforms": ["ios", "android"],
    "android": {
      "package": "com.thestillness.app",
      "versionCode": 1,
      "permissions": [
        "android.permission.READ_EXTERNAL_STORAGE",
        "android.permission.WRITE_EXTERNAL_STORAGE",
        "android.permission.READ_MEDIA_IMAGES",
        "android.permission.READ_MEDIA_VIDEO",
        "android.permission.POST_NOTIFICATIONS"
      ]
    }
  }
}
```

### Шаг 3: Создать APK через EAS Build

Выполнить команду в терминале:
```bash
eas build --platform android --local
```

Система спросит:
- Build type: выбрать **apk** (не aab)
- Confirm: нажать **y**

### Шаг 4: Дождаться завершения

Процесс создания может занять 5-15 минут.

По завершении вы получите сообщение:
```
✓ Build finished
Download APK: https://...apk
```

### Шаг 5: Загрузить APK файл

Скопировать ссылку из сообщения и открыть в браузере, чтобы загрузить APK файл.

Или использовать команду:
```bash
eas build --platform android --status
```

Чтобы посмотреть статус последней сборки.

## Способ 2: Локальное создание APK (если первый способ не работает)

### Шаг 1: Установить Android SDK

1. Загрузить Android Studio с https://developer.android.com/studio
2. Установить Android Studio
3. Запустить и установить Android SDK (Tools → SDK Manager)

### Шаг 2: Установить Java JDK

```bash
# Скачать с https://www.oracle.com/java/technologies/downloads/
# Установить Java 11 или выше
java -version  # Проверить установку
```

### Шаг 3: Установить Expo prebuild

```bash
npm install -g expo-cli
```

### Шаг 4: Создать локальный APK

```bash
cd C:\Users\mvant\TheStillness

# Очистить старые сборки
npm run clean  # если есть этот скрипт

# Создать APK
npx eas-cli build --platform android --local
```

## Установка APK на телефон

### Способ 1: По email или облаку

1. Отправить APK файл по email
2. Получатель открывает email на телефоне
3. Нажимает на файл, нажимает "Установить"

### Способ 2: Через USB кабель

1. Подключить Android телефон к компьютеру USB кабелем
2. Перетянуть APK файл в телефон или использовать adb:
```bash
adb install path/to/app.apk
```

### Способ 3: Через облако (Google Drive, OneDrive и т.д.)

1. Загрузить APK на Google Drive
2. Получить ссылку на скачивание
3. Отправить ссылку другому человеку
4. Они скачивают файл на телефон и открывают его

### Способ 4: Создать web-страницу для скачивания

Создать HTML файл:
```html
<!DOCTYPE html>
<html>
<head>
    <title>TheStillness App</title>
</head>
<body>
    <h1>TheStillness - Приложение для здоровья психики</h1>
    <p>Версия 1.0.0</p>
    <a href="thestillness.apk" download>Скачать приложение</a>
</body>
</html>
```

Загрузить на хостинг (например, GitHub Pages) вместе с APK файлом.

## Требования для установки на телефон

### Для Android:
- Android 8.0 (API 26) или выше
- 100-200 МБ свободного места
- Интернет соединение для первого запуска
- Разрешение на установку приложений из неизвестных источников (в настройках Security)

### Для iOS:
- iOS 13.0 или выше
- Нужна TestFlight ссылка (требует Apple Developer аккаунта)

## Решение проблем

### Проблема 1: "eas-cli not found"
```bash
npm install -g eas-cli
```

### Проблема 2: "Android SDK не найден"
```bash
# Установить Android SDK tools через Android Studio
# Или установить через командную строку:
android list sdk
```

### Проблема 3: "Ошибка при сборке"
1. Очистить node_modules: `rm -rf node_modules && npm install`
2. Проверить версию Node.js: `node --version`
3. Проверить app.json на синтаксис ошибки

### Проблема 4: "Не устанавливается на телефон"
1. Убедиться, что разрешена установка из неизвестных источников
2. Проверить версию Android (минимум 8.0)
3. Попробовать через adb: `adb install app.apk`

### Проблема 5: "API сервер не доступен"
1. Убедиться, что сервер запущен: `npm start` в папке server
2. Проверить IP адрес в `src/services/api/client.ts`
3. Проверить, что оба устройства в одной сети WiFi

## Версионирование APK

Каждый раз при создании новой версии нужно обновить номер версии:

### В app.json:
```json
{
  "expo": {
    "version": "1.0.1",
    "android": {
      "versionCode": 2
    }
  }
}
```

Правило для версионирования:
- **1.0.0** → **1.0.1** = исправление ошибок (patch)
- **1.0.0** → **1.1.0** = новые функции (minor)
- **1.0.0** → **2.0.0** = большие изменения (major)

## Защита при распространении

Перед тем как отправить APK кому-то еще:

1. **Проверить логины и пароли** 
   - Убедиться, что в коде нет жестко закодированных логинов

2. **Проверить API ключи**
   - В `src/services/api/client.ts` убедиться что правильный API хост

3. **Проверить версию**
   - Обновить версию в app.json перед каждой публикацией

4. **Провести тестирование**
   - Установить на реальном телефоне и проверить функциональность

5. **Проверить разрешения**
   - Убедиться что все разрешения в app.json необходимы

## Загрузка в Google Play Store (опционально)

Для публикации в магазине нужно:

1. Создать Google Play Developer аккаунт ($25 один раз)
2. Подписать APK файл приватным ключом (keytool)
3. Загрузить на Google Play Console
4. Пройти модерацию (1-3 часа)

Подробнее: https://developer.android.com/guide/publishing
